Panduan Lengkap Penggunaan Aplikasi Portal Masjid

Langkah-langkah praktis pengelolaan data DKM, laporan kas, dan berbagi ke jamaah maupun sesama admin

1 Identitas Masjid, Logo, Banner Utama & Kalimat Beranda

  • Ubah Nama & Kalimat Beranda: Klik tombol [Edit Kalimat] pada halaman utama untuk mengganti Nama Masjid, keterangan di bawahnya, kalimat sambutan, dan teks tombol.
  • Ganti Banner Utama: Klik [Ganti Banner] di halaman utama untuk mengganti foto latar belakang (bawaan Masjid Nabawi) melalui unggahan foto dari perangkat, URL gambar, atau pilihan tema siap pakai, lengkap dengan pengatur lapisan gelap netral (0%–80%).
  • Logo Masjid & Kop Surat PDF: Klik menu Ganti Logo di bilah atas untuk mengunggah Logo Utama (tampil di header/footer) dan Logo Kop Surat (tampil otomatis di bagian atas laporan PDF).

2 Jadwal Sholat (Indonesia & Internasional), Kalender Hijriah & 19 Bahasa

  • Tanggal Hijriah & Hitung Mundur Otomatis: Bilah paling atas menampilkan tanggal Masehi dan Hijriah otomatis sesuai zona waktu kota, disertai hitung mundur waktu sholat berikutnya di halaman utama.
  • Atur Kota/Negara: Klik Cari Lokasi / Edit Jadwal Sholat, pilih tab 🇮🇩 Indonesia (jadwal otomatis Kemenag RI) atau tab 🌍 Internasional (kota & negara dunia), lalu klik Simpan Jadwal Sholat.
  • Pilihan 19 Bahasa: Gunakan menu bahasa di kanan atas untuk menerjemahkan tampilan antarmuka ke 19 bahasa internasional.

3 Pengumuman Berjalan, Agenda Kajian, Galeri Foto & Profil DKM

  • Pengumuman DKM: Klik tombol Edit di ujung kanan bilah pengumuman kuning untuk memperbarui informasi berjalan bagi jamaah.
  • Kajian & Fasilitas: Gunakan tombol Tambah Agenda atau Tambah / Edit Fasilitas, serta ikon pensil pada tiap kartu untuk mengubah atau menghapus item.
  • Galeri & Folder: Klik Kelola Folder untuk membuat kategori album, lalu klik Unggah Dokumentasi untuk menambahkan foto kegiatan.
  • Profil DKM & Kontak: Klik Edit Profil DKM untuk memperbarui sejarah, visi misi, serta nama & jabatan pengurus inti (otomatis tersinkron ke tanda tangan laporan PDF).

4 Transparansi Kas Masjid, Impor CSV, Cetak PDF & Infaq Digital

  • Catat Mutasi Kas: Klik Input / Edit Kas untuk mengatur Saldo Awal serta mencatat pemasukan atau pengeluaran menggunakan kalender tanggal.
  • Impor CSV & Laporan PDF: Gunakan Download/Upload Template untuk input massal CSV. Klik Cetak PDF untuk mengunduh laporan resmi berkop surat lengkap dengan tanda tangan Ketua & Bendahara DKM, atau klik Kirim Laporan untuk mengunduh PDF sekaligus membagikannya ke WhatsApp.
  • QRIS & Rekening Infaq: Buka Infaq Digital → Pengaturan QRIS & Rekening untuk mengganti gambar QRIS dan nomor rekening transfer bank masjid.

5 Berbagi ke Jamaah: Kirim Update File HTML (Mode Baca Saja / View-Only)

  • Klik tombol hijau Kirim Update File HTML ke WA (atau menu Kirim Link HTML di bilah atas) setiap kali ada pembaruan jadwal, kajian, atau saldo kas.
  • Aplikasi akan membuat file .html mandiri yang sudah memuat seluruh data terbaru Anda namun terkunci (tanpa tombol edit) sehingga aman dibagikan ke grup WhatsApp jamaah.
  • Di HP, file langsung terlampir otomatis ke WhatsApp; di laptop/komputer, file terunduh otomatis dan siap dilampirkan lewat ikon Dokumen (📎) di WhatsApp.

6 Kerja Sama Pengurus: Sinkronisasi Database HTML (Admin 1 → Admin 2)

  • Kirim ke Admin 2 (Tetap Bisa Diedit): Pada bagian Kas Masjid atau menu Kirim Link HTML, klik tombol kuning Kirim HTML Master ke Admin 2. File .html Master akan terkirim lewat WhatsApp lengkap dengan seluruh hasil input terakhir beserta seluruh tombol editnya.
  • Lanjutkan Input oleh Admin 2: Admin 2 cukup membuka file .html Master tersebut di browser, atau menekan tombol Muat Update DB lalu memilih file .html Master / .json yang dikirim Admin 1 untuk menyinkronkan database dan melanjutkan penginputan.
  • Penyimpanan Otomatis: Setiap perubahan tersimpan otomatis di browser perangkat masing-masing admin. Gunakan Unduh DB (.json) secara berkala sebagai cadangan data.
